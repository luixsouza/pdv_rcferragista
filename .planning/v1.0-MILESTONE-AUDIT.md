Four cross-phase consistency findings were fixed during the audit:
1. `cancelledInstallmentIds` now written on the refunded Sale in all three return paths (Sales/Returns/POS).

4. Fiscal docs render fractional quantities in pt-BR comma notation.

All three return entry points and the estorno path now cancel installments and cap haver consistently; devolução reversal restores installments and unlocks estorno; crediário balances exclude cancelled/abated installments.
